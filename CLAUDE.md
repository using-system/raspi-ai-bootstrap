# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

raspi-ai-bootstrap uses Ansible to bootstrap a Raspberry Pi into a self-hosted AI node with Claude Code, MCP tools, Telegram integration, and local LLM inference.

## Repository Status

This project is in early development on the `features/bootstrap` branch. No source code, build system, tests, or CI/CD have been implemented yet. The target automation tool is Ansible.
